# anything2explainer — кандидат для ФОТО галереи КОРА

Отложено на рассмотрение. Проверено 2026-09-17 (HEAD репозитория от 2026-09-13).

- Репозиторий: https://github.com/Vincentwei1021/anything2explainer
- Возможное применение: ФОТО галерея КОРА (задачи t13 «Фотосессии по отделам, печать галереи»
  и t22 «Лендинг и виртуальная галерея» в `index.html`).

## Что это

Skill для Claude Code / Codex, а не CLI и не приложение. Даёшь тему — агент делает
видео-объяснялку: исследование с источниками → текст диктора → TTS с покадровым
таймкодом → раскадровка → параллельные агенты пишут по Remotion-компоненту на кадр →
рендер → QC-агенты по главам. Каждый кадр рисуется кодом (Remotion 4, React + TypeScript),
стоковое видео и генеративные модели не используются.

В поставке: компилируемый шаблон Remotion, библиотека графических примитивов и световых
эффектов, скрипты озвучки/раскадровки/рендера/количественного QC, стайлгайд и словарь
анимации, протокол разделения работы между агентами и эталонный фильм про RAG со всем
«бумажным следом» (исследование → сценарий → раскадровка → исходники кадров → QC-отчёты).

## Параметры

- Выход: 1280×720, 30 fps, H.264 MP4; длительность 2–8 минут (задаётся заказчиком).
- Постоянные слои: субтитры 44px, нижняя полоса прогресса по главам, верхний HUD,
  карточки глав.
- Стиль ровно один: чёрный фон, белая линейная графика, фиолетовые акценты, сверхжирный
  заголовочный шрифт. Переключается только фон: `bg: 'stars' | 'dots'`.
- Затраты: 1–3 часа реального времени на ролик, 8–14 параллельных агентов, 2–3 ГБ диска.
- Требования: Node ≥18, ffmpeg, Python 3 + venv (edge-tts, numpy, pillow, scipy).
  Проверено на macOS, Linux заявлен, Windows не тестировался.
- Четыре точки согласования с заказчиком: длительность и язык; текст диктора; движок
  озвучки; первые 30 секунд.

## Ограничения, критичные для нас

1. **Нет русского языка.** Поддерживаются только китайский и английский (`lang: 'zh' | 'en'`):
   под каждый язык свой TTS-голос, своя модель темпа речи и свой бюджет субтитров
   (16 иероглифов / 48 символов на блок). Русская озвучка возможна только через путь
   «принеси свой TTS» — кладёшь готовый wav и вручную заполняешь `src/common/timeline.ts`
   и `subs.ts`. Типографика и расчёт длины субтитров под русский не настроены: это
   доработка, а не конфигурация. Самая понятная точка доработки — русский профиль
   (шрифты, темп речи, бюджет субтитров).
2. **Лицензия PolyForm Noncommercial 1.0.0.** Инструментарий бесплатен только для
   некоммерческого использования; коммерческое требует предварительного разрешения автора.
   КОРА 35 — корпоративный проект, вопрос нужно решить до начала работы. Готовые видео при
   этом принадлежат их авторам — ограничение только на сам инструмент.
3. **Только горизонтальный формат 16:9.** Вертикали 9:16 для соцсетей нет: шаблон и все
   правила безопасных зон рассчитаны на 1280×720.
4. **После озвучки текст заморожен** — номера кадров зашиты в код кадров, правка одной фразы
   перетаймливает весь фильм.
5. Не подходит для: копирования существующего видео, съёмки говорящей головы, фильмов
   преимущественно из реальных съёмок.

## Вывод

Инструмент серьёзный и хорошо документированный, но под фотогалерею в лоб не ложится: это
генератор объяснительного видео из темы, а не галерея фотографий. Сам движок (Remotion,
покадровая анимация кодом, автоматические субтитры и главы) может пригодиться, если из
фотоархива захочется сделать ролик. Перед любым использованием — решить вопрос с лицензией
и с русским языком.

Шрифты в поставке (Noto Sans SC / Orbitron / Exo 2 / Audiowide) — отдельно под SIL OFL 1.1.
У самого Remotion свои условия для компаний: remotion.dev/license.
